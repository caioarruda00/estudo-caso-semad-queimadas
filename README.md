# Estudo de caso SEMAD-GO — queimadas em Goiás (2024)

Consultoria de dados para a Secretaria de Meio Ambiente de Goiás (SEMAD-GO): análise do padrão de queimadas no estado durante a safra de seca de 2024 e recomendação de prioridades de fiscalização ambiental.

Trabalho da disciplina de Data Science (Rede XPTO).

## Objetivo

Calcular medidas de tendência central e de dispersão sobre um dataset real de focos de queimada em 31 municípios goianos:

- média
- mediana
- moda
- amplitude
- variância
- desvio padrão
- coeficiente de variação

As respostas do questionário (10 questões) registram o cálculo ou o código usado, não só o número final.
